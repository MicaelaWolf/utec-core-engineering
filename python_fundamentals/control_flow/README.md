# Flujo de control

0. positive_or_negative: Asigna un número entero aleatorio entre -10 y 10 a una variable llamada "number". Luego imprime el numero seguido de una calificación dependiendo de si el numero es positivo, negativo o cero.

1. last_digit: El script genera un número entero aleatorio entre -10000 y 10000, calcula su último dígito y muestra si este es mayor que 5, igual a 0 o menor que 6 y distinto de 0.

2. print_alphabt: Imprime el alfabeto en minúsculas, omitiendo las letras "e" y "q".

3. print_hexa: Imprime números del 0 al 98 en decimal y hexadecimal.

4. print_comb2: Imprime números del 0 al 99 formateados como números de dos dígitos, separados por coma y espacio.

5. print_comb3: Imprime todas las combinaciones únicas de dos dígitos diferentes del 0 al 9.
