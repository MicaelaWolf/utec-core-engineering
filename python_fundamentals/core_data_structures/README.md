# Estructura de Datos Básicas

0. print_list_integer: Imprime todos los enteros de una lista.

1. element_at: Recupera un elemento de una lista.

2. replace_in_list: Reemplaza un elemento de la lista en una posición específica.

3. print_matrix_integer: Imprime una matriz de enteros.

4. add_tuple: Suma dos tuplas.
