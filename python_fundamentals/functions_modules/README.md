# Funciones y Modularidad

0. islower: Devuelve True si le diste una letra minuscula y false en caso contrario.

1. uppercase: Imprime la palabra dada en una cadena en mayúsculas seguida de una nueva línea.

2. print_last_digit: Imprime el ultimo digito del numero dado.

3. pow: Devuelve el valor de "a" elevado a la potencia de "b".

4. add: Importa una función simple desde un archivo simple.

5. calculation: Suma, resta, multiplica y divide dos numeros al importar las funciones.

6. variable load: Importa la variable "a" e imprime su valor.
