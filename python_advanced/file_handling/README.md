# Manejo de archivos

0. read_file: Lee el contenido de un archivo de texto UTF-8 y lo imprime en pantalla sin modificarlo.

1. write_file: Escribe texto en un archivo UTF-8, creándolo si no existe o sobrescribiéndolo si existe, y devuelve la cantidad de caracteres escritos.

2. append_write: Añade texto al final de un archivo UTF-8 sin borrar su contenido anterior, crea el archivo si no existe y devuelve la cantidad de caracteres añadidos.
